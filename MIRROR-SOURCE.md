# Mirror provenance

This repository is a manually synchronized public mirror of the normative MMP source in
[`sym-bot/meshcognition-website`](https://github.com/sym-bot/meshcognition-website).

Current synchronization source for this branch:

- source branch: `codex/mmp-v2-spec-conformance`
- source commit: `3d66352`
- source PR: [sym-bot/meshcognition-website#12](https://github.com/sym-bot/meshcognition-website/pull/12)

After that PR merges, the final mirror commit must record the resulting source `main` commit.
Differences are resolved from source to mirror, never from mirror to source.
